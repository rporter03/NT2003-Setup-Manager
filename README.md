# NASCAR Thunder 2003 Setup Manager
A web application to help manage car setups for NASCAR Thunder 2003.

Uses React, Vite, Tailwind CSS, Typescript, and Anime.js.

## Use

[Visit NT2003 Setup Manager Here](https://nt2003-setup-manager.vercel.app)

[Demo Video](https://www.youtube.com/watch?v=LiCrxRbX3s0)

## Purpose

I created this webapp so I can manage my own setups better than what the game offers. Since there are only eight setup save slots per memory card in the game, it is not enough for me to save all of my setups. Using this app, I can just enter my setups from the game, come back to them later, and view them easily.
